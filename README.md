# FastBox Delivery System

This project is a simple logistics simulation for a fictional delivery company called FastBox.
The program reads delivery data from a JSON file, assigns each package to the nearest delivery agent, simulates the delivery, and creates a final report.

# Project Files

- `main.py` - Main Python program containing the delivery logic.
- `data.json` - Default input data.
- `report.json` - Output report generated by the program.
- `test_case_1.json` to `test_case_10.json` - Additional input files used for testing.

# How It Works

The program follows these steps:

1. Read the JSON input file.
2. Read warehouse, agent, and package information.
3. Find the nearest agent to each package's warehouse.
4. Calculate the distance from the agent to the warehouse.
5. Calculate the distance from the warehouse to the package destination.
6. Add these distances to get the total trip distance.
7. Count the packages delivered by each agent.
8. Calculate efficiency for each agent.
9. Save the final result in `report.json`.

# Distance Calculation

The program uses Euclidean distance between two points.
The formula used is:
distance = sqrt((x2 - x1)^2 + (y2 - y1)^2)

# Agent Assignment
Each package is assigned to the agent who is closest to the package's warehouse.
The distance between every agent and the warehouse is checked before selecting the nearest agent.

# Efficiency

Efficiency is calculated as:
total distance / packages delivered
Agents who do not deliver any package have their efficiency left as 'null'.

# Assumptions

- Every package has a valid warehouse and destination.
- An agent starts from their given location.
- For each package, the agent first travels to the warehouse and then travels from the warehouse to the destination.
- The nearest agent is selected using Euclidean distance.
- Packages are processed one at a time.
- If two agents have the same distance, the first agent encountered in the input data is selected.
- The program supports the different JSON formats used in the provided test files.
- The report is rounded to two decimal places for distance and efficiency.

# Running the Program
Make sure Python is installed.

Run the default input:
'python main.py'
To test another input file:
'python main.py test_case_1.json'
The generated result is saved in:
'report.json'

# Testing
The program was tested using the provided test case JSON files.
The main checks are:

- JSON data is read successfully.
- Packages are assigned to agents.
- Distances are calculated.
- All packages are processed.
- The number of delivered packages matches the number of packages in the input.
- A valid 'report.json' file is generated.

# Output
The report contains:
- packages_delivered
- total_distance
- efficiency
- best_agent
